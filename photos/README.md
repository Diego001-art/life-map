# Фото села — загружайте сюда

Раскладывайте по папкам:
- `doma/` — дома. Название файла: сектор и что это, например `C4-dom-abdula.jpg`
- `mesta/` — мечеть, родник, школа, годекан, пещера: `D5-mechet.jpg`
- `tekstury/` — крупные фото стен, камня, крыш, дорог (для текстур)
- `gory/` — горы вокруг села (видно из какого сектора и куда смотришь: `E4-vid-na-sever.jpg`)
- `lyudi/` — одежда, утварь, всё что поможет сделать жителей

Сектор видно в игре в левом верхнем углу (буква + цифра). Клавиша M — большая карта с секторами.

Как загрузить с телефона/компьютера: github.com → репозиторий abdul → ветка → папка photos → нужная папка → «Add file» → «Upload files».
